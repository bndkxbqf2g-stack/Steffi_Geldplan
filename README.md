# Mein Geldplan v34

GitHub-Pages-fähige PWA für die persönliche Finanz- und Urlaubsplanung.

## Datenbasis v34

Aus den bereitgestellten Bezügemitteilungen 06/2026, 07/2026 und 08/2026:
- KR 8 / Stufe 3
- 23,1 / 38,5 Stunden = 60 %
- Tabellenentgelt 2.302,25 €
- Pflegezulage 54,00 €
- Vorweggewährung §16 TV-L 233,90 €
- Universitätszulage Pflege 98,11 €
- Praxisanleiterzulage 54,89 €
- laufendes Gesamtbrutto 2.743,15 €
- gesetzliches Netto 1.933,37 €

Variable Zuschläge, Rückrechnungen und Sonderzahlungen werden nicht in das reguläre Monatsnetto eingerechnet.

## Tariflogik

Die App enthält die TV-L-KR-Tarifentwicklung 2026–2028 und die seit 01.07.2026 geltenden §43-Zulagen für nichtärztliche Beschäftigte an Universitätskliniken/ Krankenhäusern als Planwerte.
